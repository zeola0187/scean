# 人物本體：讓角色有可持續推演的理由

## 工作目標

先為每一名被明確指定要設計的人物建立足夠完整的「目前狀態」。完整的意思是不同資訊能彼此說明，而不是每個欄位都填滿。不要套固定性格形容詞清單，也不以是否討人喜歡作為品質標準。

## 先從哪些材料理解人物

1. **可被感知的存在**：外貌、體態、年齡所處的生活階段、動作習慣、衣著與身體經驗。可以主動創作細節，但不必為每項外觀安排象徵或創傷。留意身體如何影響社會待遇與自我認識，人物的選擇又如何反映在外觀上。
2. **習慣性的判斷**：他通常注意什麼、把什麼視為重要、如何衡量代價、什麼事情讓他信任、害怕、抗拒或願意冒險。比單純貼上「善良」「冷酷」等標籤更有用。
3. **日常的表達**：他如何維持距離、建立親密感、處理問題、表達情緒。可以說明言語習慣，但正式對話範例屬於另一個專門工作。
4. **具有作用的過往**：挑出足以影響現在行為的事件、長期環境或關係。不必刻意補一段重大悲劇，也不必寫完整人生履歷。
5. **內在推力與可選方向**：有人渴望達成具體事情，有人追求長遠理想，有人主要靠興趣或眼前情境行動。不要把每名角色都塞進「想得到什麼／怕失去什麼」的固定公式。

## 人格不是不可改動的靜態核心

區分一時的情緒、長期形成的傾向與逐漸改變的信念，但不要把它們切成彼此隔絕的盒子。職業、習慣、權力位置、創傷、成就與親密關係，都有可能在多年中改變人物的判斷；已形成的性格也會反過來影響人物選擇什麼環境與關係。

例如：一名原本凡事相信制度的資深調解員，可能在多次見過制度失靈後，開始把當事人的處境放在條文之前。他的專業身份不只改變說話方式，也可能逐步重排他重視的價值；這不需要解釋成前後設定錯誤。

## 表面矛盾、自我認知與真正動機

當人物同時表現出不同方向的特質，先尋找背後判斷標準是否隨利益、時間、親疏、責任或情緒改變。真正動機、自我理解、對外理由可以不同；人物也可能不了解或不承認自己的原因。這些差異有創作價值時，應把足以支持演繹的心理機制寫清楚。

但不必把所有人物塑造成充滿秘密或自我欺騙的複雜個體；坦率、單純、頑固或極端，都可以是刻意且成立的人格。

## 保留空間的方式

可以明確寫「這個人為何重視某事、哪些因素會影響選擇」，不要把每個條件轉成對應的固定行動。人物可能改變主意、受他人說服，或因為沒有預料到的事件作出不同反應。製卡者若要求嚴格的行為規則，才將它當作特殊設定處理。

## 完成檢查（內部）

- 外貌和身體經驗是否已足夠描繪人物，而非只留下空泛形容？
- 重要特質是否有可理解的心理或經驗脈絡？
- 有沒有不必要的強制目標、創傷或性格平衡？
- 如果人物持有互相衝突的態度，是否說得通，又保留 RP 中的選擇可能？
- 是否把假設性的未來事件偷寫成已發生的過往？
