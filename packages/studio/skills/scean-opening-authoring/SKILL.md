# SCEAN 開場白創作

依使用者提供的完整創作規格工作，為玩家建立一個正在生活、值得開始的世界，保留其決定後續故事的自由。負責 `first_mes`、作者要求的 `alternate_greetings`，以及必要且已獲授權的共用歷史一致性維護。

創作或修訂前，完整閱讀 [創作規格](references/creative-guide.md) 與 [作者審閱、修訂與保存流程](references/authoring-workflow.md)。兩份參照完整保留所提供的自然語言規則；不把本頁摘要當成規格的替代品。實際讀卡、保存或同步世界書前，閱讀 [本版工具對應與能力邊界](references/studio-contract.md)。

## 工作重點

- 讀取當前 Session 已選工作副本的相關設定、世界書、現有全部開場及初始狀態。已足夠創作就直接工作；只有影響作者意圖、玩家核心背景或硬性設定的缺口才詢問。
- 以近景和自然人物活動呈現世界；可用必要旁白、多鏡頭及 NPC 內心。保持同一起始時間切片，多鏡頭最後回到玩家。沒有固定字數、人數、衝突、鉤子或問句收尾。
- 允許普通生活細節與符合世界書生成規則的新人物／場所；不替玩家決策、發言、設定主觀內心或重大身世。讀者看見的資訊不等於玩家角色已知，也不因此取得 Runtime 權限或記憶。
- 世界設定、玩家核心背景、共用世界書、State Blueprint 與 InitialState 保持一致；不為開場改變初始值。修正創作構想來配合設定，不暗改 State。
- 未指定文風時，以相同場景／人物／基本事件提供少量有差異的試寫；已有明確要求就直接採用。試寫不保存為正式開場，不建立共用歷史。文風確認後重新構思正式情境，不必沿用試寫。
- 預設一篇；只有作者要求才新增其他開場。各篇獨立修訂，不連動重寫其他篇。只選一個入口，不把未選開場的即時事件當成已發生歷史。
- 提交前自行審稿，向作者呈現完整正文；不預設展示內部評分、未揭露秘密或未來劇情。優先局部修訂，保護未指定改動的內容。
- 作者明確確認後才正式保存；這是 Agent 工作規範，不是 Host 的新確認欄位。經授權的必要共用歷史可同步，不逐項重問；權限不足或部分保存失敗仍須如實告知，不能假稱全部完成。

## 接入現有平台

透過已註冊 Card Studio 工具使用最新 revision，讀回並核對修改範圍。單一既有正文用精確文字替換；空欄位或開場陣列用局部 JSON Pointer 更新；世界書條目用穩定 ID 的 lorebook 工具。保留 macro、HTML/CSS、未知資料與非目標開場。

本版沒有每篇開場的獨立標題／簡介欄位。需要時在對話中保留不劇透的交付說明，不混入正文，不自行發明卡片欄位。既有舞台的主／替代開場選擇、共用初始狀態與固定 Run Snapshot 流程照常使用。

不修改人物核心設計、Blueprint、InitialState、Writer Pipeline、Preset、`system_prompt` 或 `post_history_instructions`。本 Skill 不自動開 Run、授權付費模型或執行卡片腳本；文學品質、敘事知情範圍及模型是否遵循規格，未經真模型觀察就標為未測。權限、Session、lease、revision CAS 與資料結構才由現有 Host 契約強制。
