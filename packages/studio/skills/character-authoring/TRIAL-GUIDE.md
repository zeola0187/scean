# 角色塑造 Skill α1：人工試用說明

本包是依據 2026-10-09 與製卡者的三十題訪談及後續規格檢查，由新文字撰寫的**方法論原型**。它不是完整的 Card Studio 插件，不包含 DSH 執行碼，也還沒有在實際 RP 上驗證效果。

## 內容

- `character-authoring/SKILL.md`：入口、職責、授權界線、固定七階段、回覆要求。
- `character-authoring/references/person-design.md`：人物外貌、人格、重要經歷、目標與心理機制。
- `character-authoring/references/social-and-situational.md`：身份、既有制度、情境、重要人物間的關係。
- `character-authoring/references/review-and-delivery.md`：假設情境驗證、最小充分描述、資料編排與交付。
- `CODEX-INTEGRATION.md`：提供 Codex 的隔離整合任務文字。

## 第一輪試用方式

優先找一張你熟悉、已有多名固定角色的卡片；在**工作副本**中完成，不要直接碰日常使用的原版。用一個不完整但明確的大方向測試，例如：「我希望這兩個角色的個性和日常矛盾更有特色，幫我先討論一下方向，再修改。」

至少觀察以下六件事：

1. **創作能否起步**：資料不足時，會不會不必要地要求補完每一項設定？
2. **工作有無越界**：會不會擅自替世界補制度、替玩家安排關係，或設計臨時 NPC？
3. **人物是否立得住**：是否能清楚交代角色的判斷根據，又不把極端人格自動中和？
4. **衝突是否合理攔截**：遇到與既有素材直接相反的事實，是否先提出具體差異並詢問？
5. **情境驗證有無污染成品**：是否能展示可能反應作為參考，卻不把測試劇情與固定行動寫入卡片？
6. **交付是否像種子**：最後是否短而充分，支援自由演繹；沒有複製長篇分析過程？

第二輪可以讓同一張卡交給不同模型或 Preset 演繹，觀察是否「保留人物核心邏輯，同時容許細節差異」。**不要把一次推演當成對整套人格設計的證明。**

## 評分方式（人工）

每一項可記「符合／部分符合／不符合」，並附一個真實對話片段作為證據。不需要建立自動評分器；先看實際創作手感，再決定是否修改方法論。
