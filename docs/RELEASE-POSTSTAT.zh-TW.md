# SCEAN 1.6.3-local.w29.2d.rc3.1

Writer 定稿後，由 PostStat 承接正文並合理裁定未明說的時間、耗時與世界狀態。
Director／Writer 不必再提供時間候選、sourceRefs 或逐項證明。Host 保留身份、
私密權限、Blueprint、時間算術、版本／epoch、容量及原子提交，沒有正文語義審計。

合法正文先保存；PostStat 格式錯誤僅有界續算結算，最多兩次派送，共用期限。
日曆到期不等於已發生，事件結果追加保存；SourceCut、背景 epoch、rollback／
regenerate 和未知提交查收據仍保留。玩家不滿意已提交的裁量可回滾。

這是已安裝且玩家於 2026-10-28 確認通過的 poststat.1 完整成果，包含其必要
Runtime／Studio 與前置時間修補；僅更換發布版本、來源公告與文件 metadata。
未混入兩輪未採用的 Natural Runtime A/B／自然語言 handoff 實驗。

## 驗證與限制

- 原封版離線 643 項：642 通過、0 失敗、1 舊 reader fixture 略過。
- 原有界真模型 24 機會、85 客戶端 HTTP（DeepSeek 46／Gemini 39）：23 提交。
  Gemini 一個刻意格式故障案例保留正文並在固定期限停止；不是 24／24 提交。
  費用未知。這次發布不新增付費模型、不重裝或修改正式資料。
- 原安裝 17 份 Run 唯讀相容；本版不暗遷無 Clock 的舊 Run。
- 新 v13 保存與 v2 續算／通知 sidecar 不能交給 timecal.4 舊 reader。
  降版前保全升級後資料，不能以舊 home 備份覆蓋新資料。
- 本次發布包／白名單／授權／來源驗證另列 detached receipt；不把未設定 CI 說成通過。

## 使用

安裝完整 Suite。原團直接用自然語言送出行動／轉場，由正文後結算。
有合法正文但結算失敗時，使用「查看已保存正文」及可用時的「繼續結算已保存正文」。
來源已變更、兩次額度／期限用盡、權限／持久化錯誤會停止，不無限派送。
