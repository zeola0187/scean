# W29 日曆與論壇閱讀

舞臺書架的「日曆」「論壇」開啟獨立閱讀視窗；關閉後回到故事。閱讀、切日、翻頁及查看留言不會派送模型或推進故事時間。

日曆顯示 Host 的故事時間、自訂曆法日期、七日窗口及已公告公共事件。可回看過去日期；計畫、進行中、已結束與條件未知分開顯示。未公告的未來計畫不提供給讀者。前端不自行推算時間或事件結果。

論壇依故事發布時間顯示主文，分頁讀取，點選後可讀完整正文及跨日留言。作者沿用正文角色色彩；每則保留原始故事時間、回覆主文與來源。角色言論仍是主觀陳述，玩家閱讀不會更新角色知識或世界 State。第一版只讀，不提供玩家發文、留言或管理，也不讀私人日記。

在既有「閱讀與舞臺設定 → 舞臺全域設定 → Agent 模型」及本局 Agent 設定中，增加「日曆 Calendar」「論壇 Forum」。未另設時分別繼承 Stat 與 Character；本局可覆寫全域。論壇主文與留言共用論壇模型，作者身份、角色自己的背景／State／合法 Memory 與 SourceCut 仍按發言角色選取。劇情 Character 諮詢維持原 Character 路由。

新背景工作在建立時固定模型路由，持久保存引用；重試、重啟及提交沿用同一路由。指定模型失敗時明確報錯，不跨供應商回退。缺少既有路由收據的未完成工作不會偷偷重新綁定。完整 Host 備份應保留 model-route-pins；可攜 Run 匯入後若缺少未完成工作的 Host 路由收據，該工作明確失敗並等待處理，已發布內容仍可讀。

世界日常運作沿用 Phase 2A 的明確啟用契約：新劇本 Snapshot 的 worldRoutineDefinition 及符合世界設定的論壇媒介。此輪不自動改寫卡片、劇本或舊 Run，也不替未設定的故事發明論壇；尚未啟用、媒介未設定／不可用、無合適作者及角色拒絕皆保留真實狀態。

儲存維持 v9 與原 300000 節點／16 MiB 上限。背景 job 僅新增固定路由的小型引用；模型路由明細留在 Host metadata，不放進角色 Prompt。Diary 仍只有既有顯式介面，沒有新增自動頻率。

日精度／時段精度下，當前已驗證 calendar cut 中、於同一權威 Clock 公告的公共計畫可立即閱讀，不需要假裝整日或整個時段已經結束。這項即時閱讀投影不改故事時間、不開放未公告事件，也不改歷史 Agent 資訊截點。
