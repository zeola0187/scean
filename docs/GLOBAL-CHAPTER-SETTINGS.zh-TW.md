# 舞臺全域設定：章節、模型與金鑰

SCEAN Suite／Runtime／Studio 公開版本為 **1.4.1**。在 DSH 安裝／更新使用主頁網址 `https://github.com/zeola0187/scean`，不需指定私人分支。套件身份與工作區資料契約保留；本發布流程不改現役安裝、私人 Profile、Run 或既有金鑰。

## 使用方式

1. 開啟 **SCEAN 舞臺 → 舞臺全域設定**。不必先開故事或選卡。
2. 設定同區的三個開關：**啟用章節分析與摘要**、**啟用章節記憶召回**、**啟用向量搜尋**。章節召回需要另外兩項同時啟用。
3. 選擇向量供應商與模型。可用設定類型為 OpenRouter、OpenAI、OpenAI 相容服務；自訂服務填基底網址與模型正式 ID。OpenRouter 可選限定 Nebius。模型範例不是已完成連線驗證的模型清單。
4. 在遮罩的 **服務金鑰（留空保留）** 欄位自行輸入 Key。欄位永不回填原值；留空再次保存會保留已保存的 Key。更換供應商或網址時，不能把原 Key 靜默轉交到新目的地，須重新輸入該服務的新 Key。
5. 舊章排序可沿用舞臺目前模型、指定舞臺已註冊的供應商／模型，或另選 OpenRouter、OpenAI、OpenAI 相容生成服務。後三種提供獨立的遮罩 Key 欄位。排序使用結構化生成模型，不是專用 rerank API；目前沒有連線測試按鈕。
6. 按 **保存並套用全域設定**，確認畫面顯示已保存、版本與立即套用結果。正常保存不需重啟；設定跨 Run 與完整重啟保留。保存或開啟設定頁都不發送模型請求。

設定屬於目前舞臺 Host／DSH Profile，所有 Run 共用。不同 Profile 或資料根目錄的設定隔離，不需也不會把 Key 寫進每張卡或每個 Run。若服務缺少安全憑證 API，畫面會拒絕保存，不改存瀏覽器、卡片或其他明文設定檔。

## 已有環境變數的使用者

環境變數保留為**可選、唯讀備援**。畫面只顯示「可用／未找到」與目前來源，不顯示值，也不把值搬移到憑證儲存。優先序是 **本頁已保存的 Key → 明確勾選的環境變數備援 → 未設定**。若環境來源已可用，可不重填 Key，只需確認備援選項並保存。

舊 OpenRouter 名稱保持 `OpenRouter API Key`；OpenAI 使用 `OPENAI_API_KEY`；相容服務分別使用 `SCEAN_CHAPTER_EMBEDDING_API_KEY`、`SCEAN_CHAPTER_RERANK_API_KEY`。改變啟動環境後，仍需完整重啟 DSH 才能繼承新值。「可用」只表示來源存在，並不表示已通過供應商認證或模型可用性測試。

## 設定與模型工作授權

三個全域開關是 Host 功能配置，不等於排程或付費授權。每個故事仍須在 **長篇摘要、章節與原文查回 → 逐章摘要 → 分章設定與啟用狀態** 明確啟用本次自動工作。重啟後重新授權政策保留；匯入舊 Run 的旗標也不會自動授權。

全域設定保存／清除會解除已有的章節工作啟用狀態，不啟動新請求。待已接受的故事或模型工作結束後才能保存全域配置；保存期間拒絕新的相關工作。更新模型或 Key 後會重建召回介面與快取，之後重新啟用時可能增加冷快取向量化用量。

章節工作仍依累積門檻、近期緩衝與自然端點觸發。舊章存在時，每輪檢索可能產生查詢向量與排序用量；首次建立快取還需要章節向量化。這次驗收只用合成 Key／模型與 mock transport，新增付費生成和外部 embedding 均為 **0**。

## 安全儲存與權限

設定與自有 Key 使用 DSH 原生憑證記錄 API，存於 DSH 管理的 `<DSH_HOME>/.credentials.yaml`，以 Host／Profile 命名空間隔離。單一記錄的設定、版本與 Key 一起在原生寫入鎖下原子替換；只操作 SCEAN 自己的記錄，不列出、讀取或搬移其他供應商的既有 Key。

這沿用 DSH 既有檔案保護，不是新增的加密保險箱。其本機提供器使用私有檔案權限；Windows 的保護依賴 DSH_HOME 的作業系統 ACL，SDK 不宣稱以 POSIX mode 驗證 Windows ACL。請依原有 DSH 憑證檔案政策保管該目錄與備份。不要手動編輯憑證記錄。

Key 在瀏覽器以一次性 Host 公鑰及 AES-GCM 封裝後才進入 RPC。完整 Key 不回傳前端，不出現在卡片、Snapshot、Run 備份、Inspector、模型 Prompt／Trace、用量日誌、Git 或 Release。開啟設定只回傳固定的遮罩狀態與非秘密配置。沒有 WebCrypto 或安全上下文時，不提供新 Key 的明文替代提交。

只有 DSH 已驗證的操作者連線可讀寫此頁；Agent、偽造的 owner 形狀 Peer、卡片／檢視綁定或一般 RPC 權限不會獲得全域設定權。正式 Desktop 與官方 DSH Web 共用相同插件服務、橋接與介面。歷史獨立試玩伺服器仍保留主機限制與唯讀正式適配器；它不會因此取得私人憑證寫入權。

## 取消、失敗與清除

- **取消未保存變更／等待** 會清除暫存 Key 輸入。尚未送出時不保存；已送出後只取消等待，不能宣稱撤回已完成的保存，請重新讀取確認。
- 保存結果未知時，章節工作會停用，不自動重送 Key。若原生服務能讀回相同操作，讀取後可確認並套用；否則畫面保持未確認狀態，請完整重啟後查詢。普通已存故事仍可讀取。
- 兩個分頁同時修改會檢查版本，舊頁不得覆蓋較新設定；重複操作不會重複寫入。
- 清除需先勾選確認。它移除本頁保存的 Key，並停用全域功能與環境備援；不刪除故事，不刪除使用者自行設定的環境變數。

正式服務連線、真實 Key 與模型品質未測，畫面明示尚未連線驗證。實際 GUI 驗收範圍與可重建證據見 `docs/global-chapter-settings-evidence/`；原生 Desktop 二進位 GUI 若未另行驗收，不能由官方 Web 的結果替代宣稱。
