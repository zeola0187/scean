# 舞臺閱讀、靈感與展示更新

本次為 1.5.0 主線功能更新，沒有建立新版 tag 或 GitHub Release。正式安裝與原有故事資料不隨原碼推送變動。

## 玩家操作

- 新回合保存後，成功通知顯示約六秒；游標停留、鍵盤焦點或頁面隱藏時暫停計時。錯誤、結果未知及需要操作的通知保留。通知消失後仍可按「查看新回合」。
- 新正文讀取完成時，定位到剛送出的玩家句子；生成途中手動閱讀、翻查舊頁會保留位置。「回到末尾」才會直接捲到底。已保存但正文尚未讀取時，頁面會補讀，不會重送生成。
- 「給我一點想法」每次明確點擊才產生五種方向。只讀最近三至五輪已提交正文，沒有工具或私人 Agent 封包。選擇方向只插入草稿，不自動送出；可收起、展開同一份結果。
- 「世界書」只顯示本局固定 Snapshot 中有明確公開標記的內容。「故事回顧」只讀有效章節摘要，並可跳回來源正文；不會因開啟視窗而生成摘要。
- 「章節與回顧」內的「自動整理故事摘要」是本局的主開關。新局預設開啟；舊局缺少設定或明確關閉時保持關閉。全域設定只處理服務與進階選項；一般摘要不必啟用向量搜尋或記憶召回。建立、讀取、重連、保存設定不會呼叫模型，僅之後保存的新回合可能觸發已啟用的自動工作。舊章補建仍須明確點擊。
- 超過單次容量的既有章節，補建時按實際模型容量與 UTF-8 大小分批，再整合成完整摘要。畫面顯示工作數及已記錄用量。中間摘要不會成為完整章節，也不改章界、正文、State 或 Memory。
- 工作卡完成展示面板後，在舞臺「本局資訊」的面板區讀取工作卡面板、預覽，確認後套用到本局。可還原原始或上一版。此能力需要本局原本已有公開 State Blueprint；沒有 Blueprint 時保留官方狀態顯示，不能藉此新增追蹤欄位。

## 資料與權限

`playerIdeas` 是一次有界、無工具的獨立模型呼叫，沿用模型路由與用量回傳；沒有自動改稿、語義評分、重試或暗中切換供應商。內容只經基本五項結構驗證，仍應由玩家判斷是否採用。

`playerWorldbook`、`playerRecap` 為唯讀公開投影。未標公開的世界書不會猜測為公開；無資料、來源失效及讀取失敗使用不同狀態。

`presentationSource`、`presentationPreview`、`presentationApply`、`presentationRestore` 沿用人類操作者與 Session／卡片來源核對。展示版本另存於 Host 本機，使用獨立 `presentationRevision`、來源比對及冪等回執；故事 head、Run version、固定 Snapshot、正文和狀態不因此改寫。Agent 仍使用既有 Card Studio 工具保存工作卡，套用至本局由玩家確認。跨 Host 攜帶展示版本不在首版保證範圍。

章節摘要分批最多十六批原文及一次整合，保留原章節、回合、commit 和來源雜湊。每個請求維持既有模型輸出上限，按實際描述的 context budget 預檢；不能容納、來源改變、取消或模型失敗時明確失敗，不截斷來源、不自動重試、不保存局部章節。各次用量如服務有回傳則累計，未知用量不冒充零費用。這與 post_stat 交易或階段恢復無關。

## 相容性與驗證界線

保留現有 Single Writer、角色私密投影、工具與預算規則、文風、最終正文 hash、post_stat 及單次原子提交。沒有實作 post_stat checkpoint／resume、世界書熱更新或舊故事遷移。私人第三方文風素材不進公開來源包或公開 Git 歷史。

測試使用 scripted 模型與隔離合成資料。原生 Host／HTTP／瀏覽器驗證只代表機制，不代表文學品質、真模型效果或真手機驗收；完整數字與已知基線失敗見本次交付回執。
