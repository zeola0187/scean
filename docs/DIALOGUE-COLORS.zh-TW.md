# 角色台詞自動分色

Single Writer 在原有同一次寫作請求中，可以附上公開角色 ID、原文片段和重複片段序號。Host 驗證後以獨立呈現資料儲存；不增加模型階段、分類器或全文重寫。原創的格式說明只處理輸出封裝，現有文風與寫作方法不變。

新回合提供有效標記時會自動分色。舊回合、舊工作流程、未提供標記、未列名或身份不確定者維持中性文字；不回填歷史。角色以固定 Snapshot 的公開 ID 配色，同名角色仍能區分，暱稱必須對應明確 ID。八色調色盤超過八個身份會合理共用，顏色不是唯一辨識方式。

只接受精確匹配的原文片段。重複台詞需指定出現序號；衝突、重疊、越界、失效 hash、未知角色、程式區塊、引用與非 speech 標記不套用。巢狀引述維持中性；無法從文字可靠推斷被模型誤標的心理或話語歸屬，因此真模型標記準確性仍需實玩驗收。局部修復或巨集替換改變正文時丟棄原標記。

呈現採安全文字節點與固定 CSS 類別，不接受 HTML、CSS 或任意色碼。正文、bodyHash、post_stat 事件來源、State、Memory 和後續模型歷史不夾入分色註記。玩家歷史分頁預算為 128 KiB，先減少完整回合數以保留有效分色；只有單一回合加標註仍超量時才明確降級為中性文字。若完整原文自身也無法容納，回報容量錯誤，不截斷原文。預設每頁最多 10 回合、API 上限 20 回合維持不變，實際依序列化大小減少。

同一回合後來取得有效標註時，顯示層可重新上色；相同呈現資料不重建文字節點。更新色彩時保留正文與閱讀位置，不推測缺少的說話者，也不改寫歷史。

存檔含有效分色時使用 schema 7，保留原文與標記；新版本仍讀取 schema 1–6。舊版不保證能讀 schema 7。降級前應先用支援新版的程式處理存檔；不要把舊資料備份覆蓋新的遊玩進度。副本回收與恢復保留呈現資料。

隔離 Scripted 測試涵蓋單次 Writer、原子提交、修復、重新生成、存檔、回收恢復、Unicode、重複台詞、同名角色與安全顯示。原生桌面與窄窗驗證包含主題對比、重新整理及草稿保留。Scripted 成功不代表真模型標記或文學品質驗收；實體 Android 尚待使用者確認。沒有付費生成或 Embedding。

本功能是 SCEAN 自行實作，沒有匯入第三方預設、Skill 或 Visual Prose HTML，也不宣稱重現其他專案的角色識別機制。
