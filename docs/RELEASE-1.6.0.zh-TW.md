# SCEAN 1.6.0

創作入口、創作工作台與舞台依已確認的產品布局整合到現有插件。

- 原生 DSH 對話只保留「創作入口／舞臺」。入口依明確配置的 SCEAN 工作區或可信對話綁定顯示，其他工作區與插件不受影響。
- 新創作對話固定工作卡；服務端限制跨卡工具與版本衝突。既有未綁對話可明確選卡，不批次遷移。
- 完整 Preset 可查看、編輯、獨立保存及重載；保存回執與版本檢查沿現有服務。新劇本固定保存時的 Preset，舊演出 pin 不被追改。
- 檢查後保存獨立劇本，再選擇既有演出或以同一劇本另開演出。演出回收及恢復保留。
- 書架先列章節名稱與摘要，再定位原文；長篇章節可向後分頁，不只顯示第一回合。
- 保留已保存預覽與狀態／面板編輯的分工；角色、世界設定、開場數量可直接唯讀查看。
- 桌面與手機頂部預設精簡為可展開資訊列。三個既有操作位於輸入框右側；空白輸入低高度，長文字自適應至上限後內部捲動。
- 收合書架／此刻會擴展實際正文寬度；保留字級與閱讀寬度設定。
- 創作入口與創作對話新增「設定」。底色與舞台共用此瀏覽器的既有顯示偏好，可重載；不修改原生 DSH 主題。不同瀏覽器或裝置各自保存。

## 驗證與邊界

本輪使用 DSH 0.2.1-rc.2 的隔離 Web／原生插件、合成卡片與 scripted provider。
1440×1000 收合兩欄時：頂部約 231→52px；空白輸入區約 194→57px；正文約 800→1310px。
390／360 窄視窗：空白輸入約 65px，右側按鈕 44×44px，輸入可用寬約 152／122px；長文上限 112px。
這是桌面瀏覽器窄視窗驗證，沒有宣稱實體手機鍵盤、Safari 或付費模型品質驗收。

固定綁定、跨卡限制、Preset CAS／重載、舊演出來源、章節向後分頁、閱讀錨點與顯示偏好均有定向離線測試。
精確結果與公開資產雜湊由 Release 附件回執記錄。先前已驗收的 b6ea 基準繼續保留；未用新一輪全面重跑取代原證據。

正式環境仍為 b6ea3e2，本輪沒有安裝或重啟。正式「返回創作對話」路徑先前因可能保存草稿超出當時唯讀授權而被審核擋下，本輪未重試；因此該正式路徑仍未完整驗收，不能宣稱全修。
兩張已回收的來源卡未恢復、未換綁；遇已回收來源仍依既有生命週期拒絕並顯示來源狀態，不擅自增加播放或編輯權限。
模型設定、Single Writer、角色權限、State／Memory 原子提交與私人文風素材不因版面調整改變。
