# Card Studio 診斷入口修正 — 2026-10-20

此修正沿用 1.5.0 套件版本，更新 main，不新增 tag 或 GitHub Release。

## 玩家會看到的改變

- 從舞臺第一次選擇「檢查這局」，編輯室可以正常顯示。返回對話後再次開啟，也會保留所選遊玩紀錄。
- 工作卡仍在載入時，可以先點「允許檢查這局」。授權處理中會顯示狀態；連續點擊不會重複送出。
- 授權被拒時會顯示錯誤，並允許重新嘗試。仍可隨時停止診斷授權。
- 原始工作卡不存在時，保留固定 Snapshot 的受限診斷，不會選取同名卡代替，也不會覆寫舊局。

診斷仍需使用者明確授權。修改卡片仍需另外討論並取得同意，保存時仍核對 expectedRevision。這次沒有擴大讀取範圍、持續權限或自動開局能力。

## 修正內容

診斷交接在編輯室第一次掛載前，會建立完整的畫面狀態；舊的不完整快取可在重新開啟時補齊。局部渲染錯誤提供重新開啟及返回對話，不清除持久資料。

診斷 RPC 使用獨立的等待／重複操作鎖。讀取工作卡不再阻擋與固定 Run 有關的授權、查詢及撤銷。原有編輯鎖、Session／頁面驗證、來源身份及版本衝突控制保留。

## 驗證與限制

相關單元與服務測試 45/45；Authoring 29/29。官方隔離 DSH Web Host 的授權操作 7/7、完整診斷回修閉環 5/5、冷啟動及來源缺失回歸 7/7。這些 UI 檢查使用合成卡片、合成 Run、實際 SDK／RPC／註冊工具；手機觸控為 Chromium 390×844 模擬。

實際安裝另核對 254 個套件檔案及 209 個 Runtime 檔案；已有 Session 的入口、重新進入及另一 Session 通過。載入中的按鈕條件以獨立測試瀏覽器暫留已完成的唯讀回覆驗證，沒有修改伺服器權限，也沒有代使用者點擊真實 Run 的授權。

使用者已回報兩個入口問題可正常操作；這不等於所有手機／瀏覽器驗收。正式入口渲染錯誤為 0，仍有一筆原有未分類的非渲染 console 訊息。此次修正沒有新增模型呼叫；真模型的診斷或敘事品質未重新驗證。

## 隔離回歸

先依 README 準備已核對的 SDK；不得對正式 Profile 執行合成測試。

```text
node scripts/w02-session-policy-host.mjs
```

在另一個終端，依序執行：

```text
node scripts/test-w02-grant-operability-gui.mjs
node scripts/test-w02-session-policy-gui.mjs
node scripts/test-w02-session-reopen-gui.mjs
```

腳本只操作自身 evidence 目錄下的合成工作區。合成 Host 的延遲與拒絕開關不進入安裝套件。

更新後，手機可重新整理頁面，再從原本那局進入檢查。若先前授權因重新載入而失效，請自行再次允許；不需要另開局或遷移舊 Run。

公開匯出另同步 README 的版本與修正說明；與已安裝修復相比，208 個 Runtime 檔案完全一致，僅一份套件 README 更新說明，所有執行程式相同。
