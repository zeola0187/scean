# 閱讀版面與按需想法

書架內的「世界書」「故事回顧」沿用固定故事版本的公開投影、搜尋、章節摘要與來源跳轉，僅按需讀取，不生成或修改故事。手機從左側「書架」進入，再按「返回故事」；來源跳轉直接回到對應正文。

輸入區旁的「想法」開啟輕量浮層，不發送模型請求。浮層內按「給我一點想法」才沿用原本的一次請求，提供五種方向。浮層可收起、Escape 關閉並返回入口；鍵盤在入口按向下鍵或 Tab 可進入操作。點選一項沿用游標插入、保留原草稿及所選文字，不自動送出；IME 組字期間不插入。切換故事或正文版本會取消並使舊結果失效，取消與失敗均不自動重試。

浮層使用獨立固定定位，位於輸入區上方；窄窗高度受限並自行捲動。開啟、收合和結果載入不改正文或輸入框座標，不自動捲動或把焦點移入輸入框。手機按鈕改為同一橫列，讓正文保有更多空間。實體手機鍵盤仍需實機確認，桌面與 390×844 窄窗由原生 DSH 合成測試核對。

本批保留章節整合及 Single Writer，不改文風、世界書、正文、State、Memory 或 post_stat 協定；不包含 post_stat 階段續跑、世界書熱修改或 Character Agency。單摘要已由實際回合證實；多章 3＋8 與自動分章仍不可宣稱完整真實端到端通過。

本次提交與推送不等於正式安裝，未重啟或關閉正在使用的 DSH。測試均為隔離合成資料及 scripted 模型，零付費模型與 Embedding 呼叫。公開來源與套件排除私人預設、第三方文風正文、真實故事、診斷與憑證；私人來源另保留已授權素材，不代表有公開授權。
