# 主角名稱與 1.4.1 升級

在舞臺「舞臺全域設定 → 預設主角名稱」保存之後新局預填的名稱，可留空。
由 Card Studio 開新局時，單一或多個開場均會顯示確認畫面，可覆寫「本局主角名稱」。
這是故事主角名稱，與 DSH 帳戶名稱分開；每個 Run 固定保存自己的名稱。
修改通用預設不改動既有故事，也不修改原始卡片或固定 Snapshot。

舊局仍可照常續讀。尚未命名的局可在「補設本局主角名稱」保存一次；
需等生成／保存完成或取消，補名僅影響後續生成，原開場及已提交正文保持原樣。
回退與重新生成保留該局固定名稱；舊的取消／失敗請求不能在改變姓名上下文後冒充原請求重試。

## 有界文字代入

只支援精確的 `{{user}}`，以 callback 單次代入，不執行巨集或腳本。
作者明列的卡片敘述、開場、合法世界書正文與字串觸發鍵、可見角色描述及 Preset 敘述
可在當次輸入投影中代入；Director、Draft、Prose、ProseRepair、Character、Adjudicate、PostStat
取得固定形狀的主角資料。新正文與合法局部修補在 BanList、PostStat 及 bodyHash 前完成代入。
卡片與來源仍是資料，不能藉此提升為 Host 指令。

不代入已提交歷史、Memory、State、ID、角色名稱、ACL、來源綁定、hash 或未知 extension。
未知巨集（例如 `{{char}}`）保持原字串。世界書只投影 literal keys，不把名稱當 regex。
HTML 只在既有 tokenizer 明確標記的文字區段代入，插入值轉義；attribute、tag、comment、
script/style 等 raw 區段不變。無效 HTML 保持原樣，沒有全檔 JSON 或原始 HTML replace。
姓名為修剪後 1–80 個 UTF-16 字元；拒絕控制字元、未配對 surrogate 及巨集括號。
特殊字元以文字顯示。自訂前端 HTML/CSS/bindings 不新增姓名巨集。

## 備份 v4 與降版

有姓名的新局或已補名局使用 `scean.run` bundle v4，包含經獨立驗證的 `playerIdentity`。
無名舊局仍依原本 v1/v2/v3 格式保存並可讀入。Run v1、Snapshot v1、Memory v2 不改號。
v4 仍驗證原有敘事來源、hash、State、ACL、回退及重新生成譜系，沒有全域資料遷移。

升級前完整備份原插件、安裝設定及相關持久資料，等待生成／保存完成後正常重啟。
舊版 1.4.0 不支援 v4，也不能保證安全寫入含姓名的新版原始 Run。
降版必須配對恢復升級前 runtime 與資料快照；升級後資料另存保留，待新 runtime 使用。
不能只切回舊插件並讓它寫入目前的新資料，亦不能直接把 v4 改號成舊格式。

本版同時整合舞臺入口對齊與可還原的素材回收；不改動第三方 Appearance 插件。
跨 Host 轉移應使用受支援的備份匯出／匯入；通用預設屬各 Host 設定，每局名稱隨故事保存。

## 驗證範圍

隔離合成測試涵蓋開新局、舊局補名、七階段投影、literal keys、HTML、安全字元、保存／匯入、
取消／重試、回退／重新生成、重啟及兩個瀏覽器分頁。兩個分頁不等同兩部實體裝置。
正式登入後 UI、實體手機、跨實體裝置、其他 OS 與真實模型文學品質未據此聲稱通過。
Studio 六項缺少歷史 SDK／SillyTavern fixture 的失敗仍保留；詳見 Release 驗證收據。
